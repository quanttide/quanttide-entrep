# quanttide-entrep

量潮创业管理

## 概述

量潮创业管理（quanttide-entrep）是量潮知识管理体系中的**创业管理**领域，以管理实践方式承载**创业主体的全生命周期**：从创业想法到主体成立、能独立运转，再到规模化经营与退出安排。

## 领域边界

本领域以**创业主体**为对象，覆盖其**创业生命周期**全程——从想法到主体成立、能独立运转，直到规模化经营与退出安排。边界由**对象**定，不由阶段定：凡是「创业主体的经营管理」，无论处在生命周期的哪一段，都在本域内。

### 判据

1. **对象判据**：被管理的是不是一个**创业主体**（新生的、尚未进入常态经营的主体，含法人、分支机构与新的经营单元）？是，则其全生命周期归本域；既有成熟主体内的常态经营，归对应职能领域。
2. **沉淀判据**：做法是否已能照着复制？首次做、无既定流程，留在本域；已有标准可循，方法迁往对应职能领域，事件与判断仍留本域。本域与相邻领域的移交由此发生，**按方法成熟度而非按阶段**。
3. **主体性判据**：本域属「xx管理」（以人为主），管的是经营者的判断与决策；可工程化的部分（云、工具、模型）只是载体，落在 `apps/`、`packages/`，不改变领域边界。

### 承载范围

- **创业机会**：机会识别与评估、商业模式探索、市场验证
- **创业计划**：商业计划书、融资计划、资源整合
- **主体设立**：主体形式、地点与时机的判断（文书执行归法务管理）
- **早期运转**：创始团队形成、产品市场匹配（PMF 的「找」）
- **规模化经营**：把主体带到可持续经营（复制、扩张、组织成形）
- **退出安排**：退出与传承的路径判断（交割、核算等执行归财务与法务）

### 边界是沉淀路线

本域是领域体系的入口容器，其他领域是沉淀池：招聘流程迁往人力资源，记账迁往财务管理，合同文书迁往法务管理，渠道打法迁往商务拓展，增长实验方法迁往增长管理，组织制度迁往组织管理。迁移的是知识资产（方法与标准），事件与判断留在本域日志。

### 与相邻领域的分工

- **business 商务拓展**：本域管创业主体本身的经营，business 管既有主体的市场开拓与合作伙伴关系。
- **strategy 战略管理**：strategy 管「往哪走」的选择，本域管把选择落成并带起一个创业主体——维度分工，不是阶段切分。
- **growth 增长管理**：本域管创业主体的规模化经营（判断与推进），growth 管可复制的增长策略、实验与效果方法。
- **org 组织管理**：本域管创业期组织从无到有，org 管既有组织的架构、制度与行政。
- **innov 创新管理**：innov 管新东西（技术、产品、模式）怎么产生与落地，本域管新东西怎么被组织成一个能活下去的主体。
- **创始人**：本域管「事」（创业主体的诞生与经营），创始人的角色与成长归创始人一线（领域待建）。
- **投资人**：本域管融资计划与资源整合（创业主体经营的一部分），资金侧的投后与关系归投资人一线（领域待建）。

### 事项归属

| 事项 | 归属 | 依据 |
|------|------|------|
| 机会识别、市场验证、商业模式探索 | 创业管理 | 对象判据 |
| 该不该设立主体、设在哪、什么形式 | 创业管理 | 主体性判据：判断 |
| 创始团队组建（找谁、怎么分） | 创业管理 | 对象判据 |
| 创业主体的规模化经营（判断与推进） | 创业管理 | 对象判据：全生命周期 |
| 退出与传承的路径安排 | 创业管理 | 对象判据：生命周期终点 |
| PMF 的「找」（第一次） | 创业管理 | 沉淀判据：无既定流程 |
| 海外公司、分公司、新业务单元设立 | 创业管理 | 对象判据：不限法人 |
| 工商注册、股权文书、合同 | 法务管理 | 沉淀判据：已可复制 |
| 招聘流程、绩效体系 | 人力资源 | 沉淀判据 |
| 增长实验、渠道投放的方法 | 增长管理 | 沉淀判据：已可复制 |
| 组织制度、核算流程、合同文书 | 组织 / 财务 / 法务 | 沉淀判据 |
| 交割、核算、确权等执行 | 财务 / 法务 | 沉淀判据 |
| PMF 的「守」（指标监控、迭代节奏） | 产品研发 / 增长管理 | 沉淀判据 |
| 拿下新渠道、做一次投放 | 商务拓展 / 新媒体运营 | 对象判据否：在既有主体里做事 |
