# quanttide-entrep

量潮创业管理

## 概述

量潮创业管理（quanttide-entrep）是量潮知识管理体系中的**创业管理**领域，以管理实践方式承载从创业想法到企业成立与早期成长的经营过程。

## 领域边界

- **创业机会**：机会识别与评估、商业模式设计、市场验证
- **创业计划**：商业计划书、融资计划、资源整合
- **早期经营**：公司设立、团队组建、产品市场匹配
- **成长管理**：规模化经营、组织建设、退出与传承

> 与 business 领域的分工：本领域承载「从 0 到 1」（创业机会与早期经营），business 承载「从 1 到 N」（商务拓展与市场开拓）。
> 与 strategy 领域的分工：本领域承载「创业过程管理」，strategy 承载「战略规划与决策」。

| `data/context` | 创业管理语境 (git submodule → quanttide-context-of-entrepreneurship-management) |

| `data/intention` | 创业管理意图 (git submodule → quanttide-intention-of-entrepreneurship-management) |
